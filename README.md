# rust-by-doing

Rust を「手を動かして」学ぶための学習リポジトリ。
[The Rust Programming Language](https://doc.rust-lang.org/book/) と
[Rust By Example](https://doc.rust-lang.org/rust-by-example/) を教材に、写経と実行を繰り返して進める。

## 進捗

| Section | 内容 | 状態 |
|---|---|---|
| 01 | 環境と最初の実行 | 完了 |
| 02 | 基本構文 | - |
| 03 | 所有権・借用・スライス | - |
| 04 | struct / enum / パターンマッチ | - |
| 05 | モジュール・コレクション | - |
| 06 | エラー処理・変換系 trait | - |
| 07 | ジェネリクス・trait・ライフタイム | - |
| 08 | テスト・クロージャ・イテレータ | - |
| 09 | スマートポインタ・並行処理 | - |
| 10 | trait オブジェクト・async 入門・Cargo 詳細・unsafe/マクロ概観 | - |
| App | 実践 CLI アプリ | - |

## 構成

- `sections/` — セクションごとの練習コード
- `apps/` — 実践で作るアプリ
